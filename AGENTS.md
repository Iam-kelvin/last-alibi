# AGENTS.md

Before changing or building anything:

1. Read `docs/COMMON_REQUIREMENTS.md`.
2. Read `docs/GAME_SPEC.md`.
3. Follow both files as the source of truth.
4. Build production-ready functionality, not demos or placeholders.
5. Test your work before moving to the next major feature.
6. Fix errors you introduce.
7. Keep the code simple, modular, and maintainable.
8. Do not change the agreed stack unless technically necessary.
9. Update README.md when setup, commands, architecture, or deployment changes.
